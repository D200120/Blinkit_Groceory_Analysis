# Blinkit_Groceory_Analysis
Blinkit Grocery Data Analysis 📊
📌 Project Overview

This project focuses on analyzing Blinkit grocery sales data to gain insights into sales performance, product demand, and category trends. The objective is to transform raw sales data into meaningful business insights using Excel-based analysis and interactive dashboards. This project demonstrates practical data analysis skills commonly used in retail and e-commerce domains.

🗂 Dataset Description

The dataset contains grocery sales records with attributes such as:

Product Name

Category

Order Date

Sales Revenue

Quantity Sold

City / Location

The data represents customer purchasing behavior across multiple product categories and time periods.🛠 Tools & Technologies

Microsoft Excel

Pivot Tables

Pivot Charts

Excel Dashboards

Data Cleaning & Formatting

🔍 Data Analysis Process

Data Cleaning

Removed duplicate records

Handled missing values

Standardized category and product names

Exploratory Data Analysis (EDA)

Analyzed total sales and revenue trends

Identified top-selling products and categories

Studied order distribution across time

Dashboard Creation

Built interactive dashboards using Pivot Tables

Added slicers for category and date filtering

Visualized KPIs such as total sales, revenue, and average order value

📈 Key Insights

Identified high-revenue product categories driving overall sales

Highlighted top-performing products with consistent demand

Observed seasonal and time-based sales trends

Discovered underperforming categories for improvement opportunities

Category-wise sales performance
